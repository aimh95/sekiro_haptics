# Sekiro PCM 프리셋 설계 v1

이 묶음은 패링/방어와 의수 10계열, 돈 던지기·유리 수리검 변형의 **직접 합성한 후보 파형**이다. 컨트롤러에서 체감 검증한 완성값이 아니다. 실제 칼의 진동을 측정하거나 게임 음원을 변환한 자료도 아니다. Windows 저장소를 열어 통합한 결과가 아니라, Claude가 기존 출력 경로에 넣어 비교할 수 있는 자산이다.

## 먼저 이해할 세 가지

PCM은 시간순으로 늘어놓은 파형 숫자다. 여기서는 1초에 48,000번 기록한다. 이 숫자는 자석의 위치·이동 방향을 직접 지정하는 벡터나 뉴턴 단위의 힘이 아니다. 내부 구동 회로와 진동 부품, 손으로 쥔 방식이 최종 느낌을 바꾼다.

Hz는 1초 동안 신호가 반복되는 횟수다. 진폭(amplitude)은 파형 숫자의 크기다. 포락선(envelope)은 진동이 언제 강해지고 얼마나 빨리 사라지는지 정한 모양이다. 같은 170Hz라도 20ms만 급하게 울리면 짧은 접촉, 200ms 동안 완만하게 울리면 지속되는 떨림을 목표로 할 수 있다. 실제 구별 정도는 손으로 확인해야 한다.

이 설계는 ‘충돌 초입 → 손에 남는 중심 진동 → 약한 여운’을 겹친다. 단순히 하나의 진동 강도만 바꾸지 않는다. 파형의 양수와 음수는 모두 사용하며, 양수만 반복하는 신호를 진동의 기본형으로 삼지 않는다.

## 도구별 느낌과 R2 준비 저항

W(s,e,k)는 Weapon의 시작 위치 s/끝 위치 e/강도 k, F(p,k)는 Feedback의 시작 위치 p/강도 k다. 위치는 장치 제어용 구간 번호이고 정확한 눌림 백분율이 아니다. 강도 역시 물리적 힘이나 체감 비율이 아니다. Weapon은 눌림 구간을 넘어가면 풀리는 걸림, Feedback은 설정 지점 이후 저항을 주는 방식이다. 아래 수치는 저·중강도에서 비교할 출발점이다.

| 계열 | R2 준비 | 기본 PCM / 길이 | 목표 느낌 |
|---|---|---|---|
| 수리검 | W(2,4,4) | 220→150Hz + 175Hz / 80ms | 작고 빠른 발사, 딸깍 |
| 창 | F(2,3) | 120→175Hz + 170Hz / 145ms | 스윽 밀어 넣는 일정한 저항 |
| 도끼 | W(3,6,5) | 95→150Hz + 170Hz / 185ms | 묵직하게 움직이는 질량 |
| 폭죽 | W(2,4,3) | 165~235Hz 짧은 봉우리 5개 / 300ms | 자잘하게 퍼지는 파열 |
| 화통 | F(1,2) | 95→155Hz + 100~260Hz 거친 결 / 160ms | 낮게 부풀며 분출 |
| 사비마루 | F(2,2) | 175→215Hz / 85ms | 빠른 연속 조작을 방해하지 않는 가벼움 |
| 우산 | W(2,4,3) | 125→180Hz + 235Hz / 165ms | 펼쳐지는 철판과 걸림 |
| 안개 까마귀 | F(2,2) | 165Hz + 140~260Hz 약한 결 / 140ms | 감각이 부드럽게 풀림 |
| 행방불명 | F(2,3) | 120→210Hz, 좌→우 / 280ms | 부채가 훑고 지나감 |
| 손가락 피리 | F(1,1) | 210Hz + 228Hz / 380ms | 약하게 살아 있는 맥놀이 |
| 돈 던지기 | W(2,4,3) | 205/250/180Hz 짧은 묶음 / 125ms | 작은 금속 알갱이 |
| 유리 수리검 | W(2,4,4) | 기본 수리검 + 285Hz 여운 / 120ms | 같은 발사 위로 가는 울림 |

의수 PCM은 기본적으로 왼쪽 1.0, 오른쪽 0.65의 숫자 배율을 준다. 왼팔 의수라는 시각적 감각에 맞춘 연출이며 정확한 물리적 방향을 재현한다는 뜻은 아니다. 행방불명/까마귀의 좌우 변화도 감성적 이동 표현이다. 장치 공진(특정 주파수가 더 크게 울리는 성질)은 이 자료에서 측정하지 않았다. 170Hz를 보장된 공진주파수로 가정하지 마라.

## 패링과 방어의 정확한 파형

둘 다 L/R=(0.95,1.0) 배율을 사용한다. 아래 A는 각 층의 계수이고 최종 혼합 파형의 최고값과는 다르다. 패링·방어로 트리거를 점유하지 않는다. L2 와이어와 R2 의수 준비를 그대로 유지한다.

| 사건/층 | 시작 | 길이 | 주파수 | A | 올라오는 시간 | 감쇠 시간상수 | 마지막 부드럽게 끄기 |
|---|---:|---:|---|---:|---:|---:|---:|
| 패링: 접촉 | 0ms | 22ms | 230Hz | .48 | 1ms | 7ms | 5ms |
| 패링: 중심 | 0ms | 60ms | 170Hz | .38 | 1.5ms | 18ms | 10ms |
| 패링: 여운1 | 6ms | 114ms | 275Hz | .15 | 2ms | 35ms | 18ms |
| 패링: 여운2 | 10ms | 100ms | 335Hz | .06 | 3ms | 30ms | 20ms |
| 방어: 무게 | 0ms | 150ms | 105Hz | .50 | 5ms | 45ms | 25ms |
| 방어: 받침 | 0ms | 80ms | 165Hz | .24 | 3ms | 25ms | 15ms |
| 방어: 거친 결 | 10ms | 150ms | 85~145Hz 성분 합 | .10 | 6ms | 55ms | 30ms |

패링의 의도는 짧은 접촉 뒤 가는 떨림이 사라지는 것, 방어는 힘을 받아내며 조금 더 오래 버티는 것이다. ‘고주파=반드시 금속’ 또는 ‘저주파=반드시 강함’이라는 물리 법칙으로 만든 것이 아니다. 둘의 시작 속도와 잔진동 길이도 함께 다르게 했다. 냉기나 온도는 진동만으로 발생시키지 않는다. ‘서늘한 칼의 감각’은 이런 접촉의 정돈과 잔향, 기존 소리의 조합으로 목표로 하는 인상이다.

## 계산 규칙 — 생성기와 일치

각 층의 시작을 0초로 둔 시간을 u, 층의 길이를 T라고 한다. 고정 주파수 사인파는 sin(2πfu)다. 주파수가 f0에서 f1로 선형으로 바뀌는 층은 sin(2π[f0u + (f1-f0)u²/(2T)])다. 변화하는 주파수를 그대로 sin(2πf(u)u)에 넣으면 의도한 순간 주파수와 달라지므로 생성기는 위 식을 사용한다.

출력 층 = A × 포락선 × 사인파 × 좌우 배율. 포락선은 코사인 모양의 부드러운 진입과 종료에 exp(-u/τ)를 곱한다. τ는 감쇠 시간상수로, 이만큼 지나면 감쇠 항이 약 37%로 줄어든다. attack/release/decay는 모두 ms로 기록하고 계산할 때 초로 바꾼다. 각 층은 시작·끝 표본이 0이다.

거친 결(grain)은 정해진 범위에서 고른 12개 이하 사인파에 서로 다른 시작 위상을 주어 합친 것이다. 실제 백색잡음 녹음이 아니다. 가중치 합으로 한 번 정의해 계수 A의 범위를 지키며, 매번 같은 seed(난수의 시작값)를 사용한다. 개별 클립을 최대 음량으로 자동 정규화하지 않는다.

AM은 진동 자체의 주파수 대신 세기가 천천히 출렁이게 하는 방식이다. 계수는 1-d/2 + (d/2)sin(2πf_am u)로, 1-d에서 1 사이를 움직인다. 의도된 질감을 위한 것으로 프레임률과 관계없다. AM과 짧은 포락선은 주변 주파수 성분을 만들기 때문에 CSV의 주파수 범위가 최종 신호의 절대 대역 제한은 아니다.

각 완성 클립의 아주 작은 평균 치우침(DC)을 부드러운 보정창으로 제거한다. 이 때문에 곡선의 끝을 튀게 하지 않는다. 보정량은 validation.json에 기록한다. 이 보정은 진동 부품의 물리적 이동 범위를 측정하거나 보장하는 작업은 아니다.

## 지속·추가 동작

- 수리검 charge_loop: 170Hz A=.14, 7Hz 세기 변화(d=.65), 240Hz A=.05. 실제 차지 상태가 확인될 때만 사용한다. 기본 수리검에 차지 기능이 있다고 가정하지 않는다.
- 화통 sustain_loop: 110Hz A=.19, 173Hz A=.13, 90~260Hz 거친 결 A=.20. 각각 17/29Hz의 작은 세기 변화를 더한다. 기본 화통의 단발 사용을 지속 분사로 취급하지 않는다.
- 사비마루 cut: 225→145Hz A=.40, 175Hz A=.13, 70ms. 실제 개별 베기 신호마다 하나씩 실행한다. 사용 시작 신호 하나로 콤보 횟수를 만들어내지 않는다.
- 도끼 impact, 창 pull, 우산 impact, 까마귀 vanish/return은 각각의 실제 사건이 확인된 경우에만 쓴다. 미지원이면 수동 비교용이다.

루프는 1초 길이의 완전한 주기를 가진 신호다. 실제 진입/종료에만 15/35ms의 부드러운 연결을 적용하고, 매 주기 처음부터 다시 페이드하지 않는다. 지속 상태를 잃으면 멈춘다. 새로운 정상 단발 이벤트가 기존 단발 여운을 자르는 것과는 다른 처리다.

## 통합·비교 방법

압축의 sekiro_pcm_v1 폴더를 프로젝트의 assets/ 밑에 둔다. Claude는 INTEGRATE.md와 preset_map.json만 먼저 읽고 이미 있는 이벤트→프리셋→출력 경로에 연결하면 된다. WAV는 논리적인 두 햅틱 채널이다. Windows 기본 재생 장치 변경이나 장치 채널 번호 추측은 필요 없다. 기존 검증된 장치 경로를 유지한다.

전역 비교 시작 게인은 0.6이다. 60% 힘이라는 뜻이 아니다. 개별 클립을 각각 최대치로 키우지 말고 전체 게인을 우선 조정한다. 믹스 후 리미터(합산 값이 지나치게 커지지 않도록 줄이는 처리)는 기존 것을 재사용한다. 강도만 크게 해서 좋게 느끼는 효과를 피하려면 패링/방어를 비슷한 체감 강도에서도 구별할 수 있는지 비교한다. 수치상 RMS(평균적인 신호 크기)가 같아도 손에 같은 세기로 느껴진다고 보장되지 않는다.

최초 비교는 스피커를 잠깐 끈 수동 재생으로 질감을 확인하고, 이어서 기존 스피커와 함께 확인하면 된다. 파일의 청각적인 소리가 곧 손의 감각은 아니다. 그다음 100/200/400ms 반복과 혼합으로 끝이 잘리지 않는지 확인한다. 각 주파수의 세기는 패드에서 조정해야 한다. 본 자료의 자동 검증은 WAV 형식·수치·길이·평균·끝점·합산만 확인하며 Windows 실시간 출력이나 이벤트 인식률을 입증하지 않는다.

## 재생성

기본 파일은 이미 들어 있으므로 최초 통합에는 재생성이 필요 없다. 수정할 때만 `python generate.py --output regenerated`를 실행한다. Python 3.10 이상 표준 라이브러리만 쓴다. 기존 폴더 덮어쓰기는 거부한다. `--pcm16`을 추가하면 진폭을 바꾸지 않고 PCM16 WAV로 내보낸다. 이 옵션은 기존 디코더 호환용이며 레거시 럼블로 전환하는 것이 아니다.
