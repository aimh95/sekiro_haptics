# 자동 검증 결과

- 독립 WAV 디코더로 22/22 파일의 48kHz/2채널/float32 형식·길이 확인.
- 유한 숫자, 단발 첫/끝 표본 0, 채널 평균 절댓값 1e-7 미만, 루프 경계 연속성 확인.
- 개별 파형의 최대 절댓값: 0.712767. 자동 피크 정규화/하드 클리핑 없음.
- 패링/방어/혼합 각 12회, 100/200/400ms 간격의 9개 오프라인 합산을 검사.
- 출력 배율 0.6에서 위 9개 합산의 최대값: 0.431974. 0.9 초과 표본 0.
- 두 루프와 두 단발을 함께 더한 가상 스트레스 합산 최대값: 0.978605. 0.9 초과 표본 80, 1.0 초과 표본 0. 합산 여유가 줄어드는 예이므로 기존 런타임 리미터를 유지해야 한다. 이는 게임에서 가능한 동시 상태라고 주장하는 테스트가 아님.
- 대표 단발/거친 질감 루프를 다시 생성해 float32 표본이 동일함을 확인.

이 검사는 파형 자산과 숫자의 오프라인 합산을 검증했다. 현재 앱의 PCM Mixer, WASAPI 버퍼 공급, Windows 라이브 실행, 실제 DualSense의 출력·주파수 응답·체감·게임 감지는 검증하지 않았다. 앱에서 임의 개수로 중첩해도 제한이 불필요하다는 뜻이 아니다.

상세 결과: validation.json / offline_checks.json. 클리핑은 표현 가능한 숫자 범위를 넘겨 잘리는 현상이다. 여기서 숫자가 잘리지 않았다고 실제 기기의 왜곡까지 없다고 보장하지 않는다.
