assets/sekiro_pcm_v1/의 PCM·트리거 프리셋을 기존 앱에 적용해줘.

토큰 절약: 필수 저장소 지침을 따른 뒤 INTEGRATE.md와 preset_map.json만 먼저 읽고, rg로 기존 프리셋·PCM 로더·의수 준비 저항의 연결 지점만 찾아라. docs/ 전체, 생성기, recipes.json, 바이너리를 읽거나 웹 조사를 반복하지 마라. WAV는 이미 생성됐다.

새 엔진 없이 기존 형식으로 변환·등록해라. 확인된 이벤트만 자동 연결하고 나머지는 수동 비교용으로 둬라. 선택/R2 입력을 사용·명중으로 간주하거나 콤보를 타이머로 만들지 마라. 이번에는 새 메모리 신호 탐색을 하지 않는다.

레거시 럼블로 대체하지 말고 PCM을 사용해라. 정상 --live ... --enemy 경로, 적끼리/표창 반응 제외, L2 와이어, 스피커 겹침 재생을 보존해라. 패링/방어는 트리거를 점유하지 않는다.

구현·빌드·필요한 회귀 검증까지 완료해라. 정상 로그는 파일로 남기고 요약만 출력해라. 마지막에 변경 파일, 검증 결과, 자동 연결/수동 전용 목록, 실행 가능한 비교 명령만 짧게 보고해줘. 체감 검증 전에는 손맛이 검증됐다고 쓰지 마라.
